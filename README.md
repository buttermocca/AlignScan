# AlignScan ♡

Windows용 영수증·카드 다중 스캔 분리 및 원근 보정 앱입니다.

## 주요 기능
- 한 스캔 이미지에서 여러 영수증/카드의 윤곽 자동 검출
- 문서별 원근 보정, 수동 4점 지정 및 모서리 드래그 수정
- 스캔 파일을 창 또는 원본 화면에 드래그앤드롭하면 자동 검출과 정렬 미리보기 실행
- 자동 찾기 감도 0~100 조절
- 보정 미리보기 마우스 휠 확대·축소 (35~500%)
- 밝기·대비·채도·노이즈 제거·먼지 제거·선명도 조절
- PNG 무손실 저장 및 JPG 품질 40~100% 지정
- 귀여운 캐릭터 애니메이션 스플래시와 파스텔 보라색 UI
- 선택형 ONNX 문서 검출 모델 및 DirectML 우선 / CPU 대체 실행

## 속도 개선
큰 스캔 이미지는 한 번만 축소한 미리보기용 이미지로 보정 탭을 갱신합니다. 밝기·대비·채도·선명도는 빠른 미리보기 경로를 사용하고 노이즈·먼지 제거도 미리보기 전용 경량 필터로 처리합니다. 저장 시에는 원본 해상도와 정밀 보정 경로를 사용하므로 미리보기 속도 개선이 저장 화질을 낮추지 않습니다.

문서 검출은 이미지의 긴 변을 1600px 이하로 제한하고 에지 검사를 최적화했습니다. Windows 실행 파일은 단일 EXE 임시 압축 해제 시간을 피하도록 폴더형(onedir)으로 빌드합니다. 실행할 때는 `dist\AlignScan\AlignScan.exe`를 실행하고 `AlignScan` 폴더 전체를 함께 보관해야 합니다.

## Windows 사용
Python 3.11 64-bit 설치 후 `run_windows.bat`을 실행합니다. Windows PC에서 `build_windows.bat`을 실행하면 `dist\AlignScan\AlignScan.exe`가 만들어집니다.

GitHub Actions는 `main` 브랜치 변경 시 Windows x64 앱 폴더를 자동 빌드하고 **AlignScan-Windows-x64-FastStart** 아티팩트로 게시합니다. 저장소의 Actions 탭에서 빌드 결과를 다운로드할 수 있습니다.

## AMD Ryzen 7 4800U / AI
기본 자동 검출과 이미지 보정은 로컬 OpenCV CPU 처리입니다. 별도의 문서/카드 학습 YOLOv8 Detection ONNX 모델을 선택하면 ONNX Runtime DirectML 공급자를 먼저 시도하고, 사용할 수 없으면 CPU로 전환합니다. 실제 GPU 연산 여부는 Windows 그래픽 드라이버와 모델 연산자 호환성에 따라 달라집니다. AI 모델은 저장소에 포함하지 않습니다.

## 사용 방법
1. JPG/PNG/TIFF 스캔 이미지를 창 또는 원본 스캔 화면에 끌어놓습니다. 이미지를 불러오면 자동으로 문서를 찾습니다.
2. 검출이 너무 적으면 감도를 높이고, 잘못된 영역이 많으면 감도를 낮춘 뒤 자동 찾기를 다시 누릅니다.
3. 문서 목록에서 영역을 선택하고 보정 탭의 미리보기에서 마우스 휠로 확대해 모서리와 글자를 확인합니다.
4. 원본 화면의 색상 모서리 점을 드래그해 크롭 경계를 고치거나, 직접 지정 버튼으로 네 모서리를 순서대로 찍습니다.
5. 밝기·대비·채도·노이즈·먼지·선명도를 조절하고 PNG/JPG로 개별 또는 일괄 저장합니다.

## 주의
자동 검출은 스캔 배경과 종이 테두리 대비에 영향을 받습니다. 결과가 정확하지 않을 때는 네 모서리 직접 지정 기능으로 수정하세요. 먼지 제거 강도가 높으면 작은 인쇄점이나 글자까지 지워질 수 있으므로 미리보기로 확인하세요.
