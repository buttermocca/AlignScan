# AlignScan ♡

Windows용 영수증·카드 다중 스캔 분리 및 원근 보정 앱입니다.

## 주요 기능
- 한 스캔 이미지에서 여러 영수증/카드 윤곽 자동 검출
- 문서별 원근 보정, 수동 4점 지정 및 모서리 드래그 수정
- 스캔 파일 드래그앤드롭 자동 검출
- 자동 찾기 감도 0~100 조절
- 작업 캔버스 마우스 휠 확대·축소(10~1200%) 및 마우스 가운데/오른쪽 버튼 드래그 이동
- 수동 네 모서리 지정 또는 모서리 핸들 이동 시 커서 주변 실시간 3배 돋보기
- 수평/수직 룰러를 직접 드래그해 기준선을 만들고, 선에 맞춰 전체 이미지 자동 기울기 보정
- 정확한 90°, 180°, 270° 시계 방향 회전 및 90° 반시계 방향 회전
- 좌우/상하 뒤집기
- -180°~+180° 임의 각도 회전(0.1° 단위 슬라이더 + 숫자 입력)
- 밝기·대비·채도·노이즈 제거·먼지 제거·선명도 조절
- PNG 무손실 저장 및 JPG 품질 40~100% 지정
- 귀여운 캐릭터 애니메이션 스플래시와 파스텔 보라색 UI
- 선택형 ONNX 문서 검출 모델 및 DirectML 우선 / CPU 대체 실행

## AI 모델 사용 시 주의 (중요)
AlignScan의 AI 기능은 선택한 ONNX 모델의 입력/출력 형식에 맞춰 동작해야 합니다. 모든 문서 ONNX 모델이 서로 호환되는 것은 아닙니다.

### yolo_doc_v1.onnx
- 학습 기본 이미지 크기: **960 × 960 px** (동적 입력 그래프일 때도 AlignScan이 960을 기본값으로 사용)
- 출력: 단일 클래스 document의 YOLO Detect 박스 (cx, cy, width, height, confidence)
- 신뢰도 기본값: **25%**, AI 검출 패널에서 5~80%로 조절 가능
- 표시되는 최고 신뢰도, 출력 텐서 형태, 입력 크기로 모델이 실제로 어떤 출력을 내는지 점검할 수 있음
- **정밀한 네 모서리나 회전된 사각형을 직접 출력하지 않습니다.** 축에 평행한 대략적인 박스만 반환합니다.
- 학습 데이터는 휴대폰 촬영 문서 사진을 대상으로 한 단일 클래스/단일 문서 검출 작업입니다. 한 장의 평판 스캔 이미지에 놓인 여러 영수증·카드를 각각 안정적으로 찾도록 학습된 모델은 아닙니다.

이 모델의 원래 pagescan 파이프라인은 YOLO 박스를 먼저 얻고, 별도의 HQ-SAM 분할 모델로 문서 마스크를 정교화하는 2단계 처리입니다. AlignScan의 AI 검출 기능은 YOLO 박스 단계만 수행하므로 pagescan 전체 파이프라인과 동일한 정밀 크롭 결과를 보장하지 않습니다.

**한 장의 스캔에 영수증/카드가 여러 개 배치된 경우에는 AlignScan의 기본 자동 찾기(OpenCV 윤곽선 검출)를 먼저 사용하고, AI 결과는 보조 후보로만 확인하는 편이 좋습니다.** 실제 작업 데이터로 학습된 다중 문서 스캔 전용 모델이 필요하다면 평판 스캐너 이미지(여러 종이가 한 프레임에 함께 있는 이미지)로 별도 학습/검증해야 합니다.

## 속도 및 원본 보존
큰 스캔 이미지는 한 번만 축소한 미리보기용 이미지로 보정 탭을 갱신합니다. 밝기·대비·채도·선명도는 빠른 미리보기 경로를 사용하고 노이즈·먼지 제거도 미리보기 전용 경량 필터로 처리합니다. 저장 시에는 원본 해상도와 정밀 보정 경로를 사용하므로 미리보기 속도 개선이 저장 화질을 낮추지 않습니다.

문서 검출은 이미지의 긴 변을 1600px 이하로 제한하고 에지 검사를 최적화했습니다. Windows 실행 파일은 단일 EXE 임시 압축 해제 시간을 피하도록 폴더형(onedir)으로 빌드합니다. 실행할 때는 dist\AlignScan\AlignScan.exe를 실행하고 AlignScan 폴더 전체를 함께 보관해야 합니다.

## Windows 사용
Python 3.11 64-bit 설치 후 run_windows.bat을 실행합니다. Windows PC에서 build_windows.bat을 실행하면 dist\AlignScan\AlignScan.exe가 만들어집니다.

GitHub Actions는 main 브랜치 변경 시 Windows x64 앱 폴더를 자동 빌드하고 AlignScan-Windows-x64-FastStart 아티팩트로 게시합니다. 저장소의 Actions 탭에서 빌드 결과를 다운로드할 수 있습니다.

## AMD Ryzen 7 4800U / AI
기본 자동 검출과 이미지 보정은 로컬 OpenCV CPU 처리입니다. 별도의 ONNX 모델을 선택하면 ONNX Runtime DirectML 공급자를 먼저 시도하고, 사용할 수 없으면 CPU로 전환합니다. 실제 GPU 연산 여부는 Windows 그래픽 드라이버와 모델 연산자 호환성에 따라 달라집니다. AI 모델은 저장소에 포함하지 않습니다.

## 작업 캔버스 조작
- 휠 회전: 마우스 커서가 놓인 지점을 중심으로 확대/축소합니다.
- 화면 이동: 마우스 가운데 버튼 또는 오른쪽 버튼을 누른 상태에서 드래그합니다.
- 모서리 수동 지정: 직접 지정 버튼을 누른 후 네 모서리를 차례로 클릭합니다. 클릭 위치 주변의 3배 돋보기가 실시간으로 표시됩니다.
- 룰러 기울기 보정: 캔버스 아래에서 수평 룰러 또는 수직 룰러를 선택하고 이미지 위에서 기준선을 드래그한 뒤 '룰러 기준 수평 보정'을 누릅니다.
- 회전과 뒤집기: '회전·룰러' 탭에서 빠른 회전, 좌우/상하 반전, 임의 각도 조정을 사용합니다. 모든 기존 크롭 모서리 좌표도 이미지 변환에 맞춰 함께 이동합니다.
- 우측 미리보기: 별도로 휠 확대/축소할 수 있습니다.

## 주의
자동 검출은 스캔 배경과 종이 테두리 대비에 영향을 받습니다. 먼지 제거 강도가 높으면 작은 인쇄점이나 글자까지 지워질 수 있으므로 미리보기로 확인하세요. 각도 회전 시 이미지 외곽은 흰색으로 채워지므로 크롭 엣지를 확인한 뒤 저장하세요.
