# AlignScan ♡

Windows용 영수증·카드 다중 스캔 분리 및 원근 보정 앱입니다.

## 주요 기능
- 한 장의 스캔 이미지에서 여러 영수증·카드 윤곽을 자동 검출
- 문서별 원근 보정, 수동 네 모서리 지정 및 모서리 드래그 수정
- 이미지 파일을 프로그램 창에 드래그앤드롭하면 자동 검출 시작
- 자동 찾기 감도 0~100 조절
- 작업 캔버스 마우스 휠 확대·축소(10~1200%) 및 가운데/오른쪽 버튼으로 화면 이동
- 수동 모서리 지정 및 모서리 드래그 시 커서 주변 4.5배 실시간 돋보기
- 문서 가장자리에서도 커서 중심을 유지하고 스캔 바깥의 흰 여백까지 보여주는 돋보기
- 수평/수직 룰러를 직접 그어 이미지 기울기 보정
- 90°, 180°, 270° 회전 및 90° 반시계 회전
- 좌우/상하 뒤집기, -180°~+180° 임의 각도 회전(0.1° 단위)
- 밝기·대비·채도·노이즈 제거·먼지 제거·선명도 조절
- PNG 무손실 및 JPG 화질 40~100% 개별 저장
- 부드러운 세이지·아이보리·로즈 파스텔 테마와 상세 캐릭터 배너
- 움직이는 영수증 캐릭터 스플래시 화면

## 작업 캔버스 조작
- **마우스 휠**: 커서 위치를 중심으로 확대·축소합니다.
- **화면 이동**: 마우스 가운데 버튼 또는 오른쪽 버튼을 누른 채 드래그합니다.
- **직접 모서리 지정**: 네 모서리를 차례로 클릭합니다. 커서 주변에 4.5배 돋보기가 실시간으로 나타납니다.
- **모서리 보정**: 분홍색 또는 녹색 모서리 점을 드래그합니다. 돋보기가 커서 위치를 중심으로 따라옵니다.
- **룰러 보정**: 수평 또는 수직 룰러를 선택하고 작업 이미지 위에 기준선을 드래그한 다음 룰러 기준 보정을 누릅니다.
- **회전·뒤집기**: 회전·룰러 탭에서 빠른 회전, 좌우/상하 반전, 임의 각도 조절을 사용합니다.
- **우측 미리보기**: 별도 휠 확대·축소 기능으로 크롭 결과를 확인합니다.

## 빠른 미리보기 및 원본 보존
미리보기용 축소 이미지를 재사용하고 가벼운 필터를 적용합니다. 실제 저장은 변환된 원본 해상도에서 수행하므로 미리보기 속도 개선이 저장 화질을 낮추지 않습니다.

회전·뒤집기·룰러 보정은 프로그램 내부 작업 이미지에 적용하며 원본 파일을 덮어쓰지 않습니다. 자동 검출은 이미지의 긴 변을 1600px 이하로 제한하며 OpenCV CPU 최적화를 사용합니다.

## Windows 사용
Python 3.11 64-bit 설치 후 `run_windows.bat`을 실행합니다. Windows PC에서 `build_windows.bat`을 실행하면 `dist\AlignScan\AlignScan.exe`가 만들어집니다.

GitHub Actions는 main 브랜치 변경 시 Windows x64 앱 폴더를 자동 빌드하고 `AlignScan-Windows-x64-FastStart` 아티팩트로 게시합니다. 실행할 때는 `AlignScan` 폴더 전체를 함께 보관하세요.

## AMD Ryzen 7 4800U
기본 문서 검출과 이미지 보정은 OpenCV CPU 처리입니다. 여러 장의 영수증을 한 프레임에서 찾는 작업에 집중하기 위해 별도 AI 모델 불러오기 기능은 제거했습니다. Ryzen 모바일 CPU에서 스캔 크기 이미지 처리가 과도한 스레드 경쟁을 일으키지 않도록 OpenCV 작업 스레드를 제한합니다.

## 주의
자동 검출은 스캔 배경과 종이 테두리 대비에 영향을 받습니다. 검출이 잘못되면 감도를 조절하거나 네 모서리를 직접 지정해 주세요. 먼지 제거 강도가 높으면 작은 인쇄점이나 글자까지 지워질 수 있으니 미리보기로 확인하세요.
